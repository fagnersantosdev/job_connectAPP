# 🤝 Job Connect App

O **Job Connect** é uma plataforma desenvolvida para servir de ponte entre profissionais prestadores de serviços e clientes que buscam soluções rápidas e qualificadas. 

## 🎯 O Problema
Muitas vezes, clientes têm dificuldade em encontrar profissionais de confiança, enquanto prestadores de serviço qualificados lutam para encontrar novos clientes de forma organizada.

## 💡 A Solução
O app centraliza essa busca, permitindo que:
- **Profissionais:** Criem perfis, listem suas habilidades e recebam solicitações de serviço.
- **Clientes:** Encontrem especialistas, comparem perfis e entrem em contato diretamente.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** TypeScript
- **Framework:** React Native / Expo (ou Next.js, dependendo da sua escolha técnica)
- **Estilização:** Tailwind CSS / NativeWind
- **Backend:** Node.js com Prisma (integrado ao ecossistema do seu portfólio)
